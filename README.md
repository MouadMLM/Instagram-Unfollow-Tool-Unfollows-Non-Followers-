# Instagram-Unfollow-Tool-Unfollows-Non-Followers-

This tool automatically unfollows users who don't follow you back on Instagram. The timing between unfollows and breaks is adjustable to prevent being flagged for spammy behavior.

Usage:
For Browser Use (F12 Developer Tools):

  Open Instagram in your browser.
    Press F12 to open the Developer Tools.
    Navigate to the Console tab.
    Copy the entire script from this repository and paste it into the Console.
    Press Enter to run the script.
    The script will automatically start unfollowing users who do not follow you back.
    The script will respect time intervals between unfollows to avoid being flagged by Instagram.

Important Notes:

   Make sure to allow the script to run without interference (e.g., pop-ups or security prompts).
    Be cautious with the number of unfollows and the time intervals, as executing too many actions too quickly might lead to being temporarily blocked by Instagram.
