# Instagram-Unfollow-Tool-Unfollows-Non-Followers-


## Description
This tool automatically unfollows users who don't follow you back on Instagram. It runs in your browser's Developer Tools (F12) using JavaScript, with adjustable time delays between actions to help avoid being flagged by Instagram for spammy behavior.

## Usage
### For Browser Use (F12 Developer Tools):
1. Open Instagram in your browser.
2. Press `F12` to open the Developer Tools.
3. Navigate to the **Console** tab.
4. Copy the entire script from this repository and paste it into the Console.
5. Press **Enter** to run the script.
6. The script will automatically start unfollowing users who do not follow you back.
7. The script will respect time intervals between unfollows to avoid being flagged by Instagram.

### Important Notes:
- Ensure no security prompts or pop-ups block the execution of the script.
- Be cautious with the number of unfollows and the time intervals, as executing too many actions too quickly might result in a temporary block by Instagram.
